# Browser validation checklist

- [ ] Local test server uses loopback and synthetic data.
- [ ] Initial page loads without uncaught error.
- [ ] Authentication/test-mode behavior is explicit.
- [ ] Changed navigation routes open successfully.
- [ ] Filters and forms update expected state.
- [ ] Loading, empty, stale, partial, and error states are legible.
- [ ] Desktop and narrow viewport layouts remain usable.
- [ ] Keyboard focus, labels, contrast, and tooltips are usable.
- [ ] Browser console has no relevant uncaught errors.
- [ ] Screenshots contain no real financial data or credentials.
- [ ] Server is stopped and results are documented.
