# Dashboard Financeiro Unificado

Plataforma financeira em Python/Streamlit para controle financeiro, investimentos, análise de empresas, metadados e IA aplicada à tomada de decisão.

## Objetivo

Este repositório será o app unificado para integrar funcionalidades hoje distribuídas em três projetos:

- `Tiago84Barros/Dashboard`
- `Tiago84Barros/Controle_Financeiro`
- `Tiago84Barros/Dashboard-Investimentos`

## Execução local

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Status

Estrutura inicial criada para migração gradual. Nenhum código dos repositórios antigos deve ser migrado sem diagnóstico prévio.
